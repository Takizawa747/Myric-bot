# Myric

**Everything in one Discord bot.** Moderation, protection, levels, economy, games, tickets, logs and more, set up in your browser, in English, Turkish and Russian.

[Website](https://myricbot.com) · [Dashboard](https://dash.myricbot.com) · [Vote on top.gg](https://top.gg/bot/1521047598918533201/vote) · [Support server](https://discord.gg/hxYWsFVWp8)

## Why Myric

- **Online 24/7.** Myric runs on a dedicated cloud server, restarts itself automatically after a problem and backs up its data every day.
- **Set up in your browser.** Every setting lives on the dashboard: log in with Discord and change your server in a few taps.
- **Exact permissions.** Every command checks the rights of the person who uses it, and Myric never acts on the server owner.
- **No unwanted DMs.** Myric only sends a DM when a server or you asked for one, and `/dms off` stops all of them.
- **Three languages.** English, Türkçe and Русский, each with its own jokes instead of word-for-word translations.
- **Nothing behind a paywall.** Every feature is free. Coins are virtual and can never be bought or cashed out.

## Features

Moderation with cases and warning steps · detailed logs · tickets with forms · welcome messages and roles · levels and voice XP · a virtual economy with a store · casino games and mini games · giveaways and polls · reaction roles · counting · AFK · modmail.

## Your data

Myric stores only what its features need, never sells or shares it, and deletes it on request.
