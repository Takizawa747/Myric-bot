FAQ

Questions, answered

Is Myric free?

Yes. Every feature is free and there is no premium tier.

Can I set Myric up in my browser?

Yes. The dashboard has every setting: log in with Discord and you see the servers where you have Manage Server. In Discord, /dashboard opens it.

Can I turn features off?

Yes: every part has its own switch on the dashboard (Features), so your server only gets what you want.

Can coins be bought or cashed out?

No. Coins are virtual: they have no real-world value and cannot be bought, sold or cashed out.

Which languages does Myric speak?

English, Turkish and Russian. Admins pick the server's language with /language and every reply follows it.

How do I delete my data?

Ask on the support server or write to Myric in a DM: the Myric team deletes it within 30 days. Moderation records stay, so servers stay safe.

Where can I get help?

Join the support server — questions are answered there.
